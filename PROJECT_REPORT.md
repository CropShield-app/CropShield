
# Person 3 — Weed Librarian Project Report

## 1. Project Objective
To organize weed information, multilingual names and advice, and photographs for a technology-enabled weed management project.

## 2. Weed Database
Five weed records have been prepared in CSV and JSON formats.

## 3. Weed Species
1. Purple Sedge — Cyperus rotundus
2. Bermuda Grass — Cynodon dactylon
3. Jungle Rice — Echinochloa colona
4. Congress Grass — Parthenium hysterophorus
5. Desert Horse Purslane — Trianthema portulacastrum

## 4. Languages
The database includes English, Telugu, Hindi and Bengali fields.

## 5. Photo Collection
Five weed photographs have been organized into species-specific folders.

## 6. Python Scripts
- make_json.py — converts CSV data to JSON.
- check_data.py — checks database structure.
- list_photos.py — lists organized photographs.
- make_photo_index.py — creates a photo index.

## 7. Output Files
- src/data/weeds.csv
- src/data/weeds.json
- src/data/photo_index.json

## 8. Validation Note
The scripts check file structure and photo paths. Weed identification, translations and agricultural advice still require review using reliable agricultural sources or qualified experts.

## 9. Limitations and Future Work

The current database contains information about five weed species in English, Telugu, Hindi, and Bengali. One photo has been collected for each weed species. The data structure, JSON conversion, photo index, and file paths have been checked using Python validation scripts.

Further work includes reviewing the agricultural management advice and translations with reliable agricultural sources or experts, improving the photo collection if required, and integrating the database with the other components of the team project.

## 10. Conclusion
The initial weed information and photo library has been organized for integration into the team's weed management project.
